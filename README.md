# City Stars Pharmacy Website

A responsive website for a local pharmacy in Kenema, Sierra Leone, built with plain HTML, CSS and JavaScript. Customers can browse products, search, build a cart and send their order to the pharmacy on WhatsApp.

Live site: [https://bahchernor884-ctrl.github.io/pharmacy-site/]

## Features
- Five pages: Home, About, Services, Products and Contact
- Product cards with images, descriptions and prices
- Live search that filters products as you type
- Shopping cart with add, remove, item count and total
- Cart is saved in the browser (localStorage), so it survives a refresh
- "Send Order on WhatsApp" builds the order message automatically
- Prescription-only medicines show a note instead of an order button
- Mobile-friendly layout using CSS Grid and Flexbox

## Built with
- HTML5
- CSS3 (Grid, Flexbox, custom properties)
- JavaScript (no frameworks)
- localStorage and the WhatsApp click-to-chat link
- GitHub Pages for hosting

## What I learned
- Structuring a multi-page site and reusing the same header and footer
- Responsive layouts with CSS Grid
- DOM manipulation, event listeners and debugging with the browser Console
- Saving and loading data with localStorage
- Publishing a site with Git and GitHub Pages

## Notes
- Product prices are sample prices for demonstration.
- Orders are sent by WhatsApp. There is no online payment.
- I used AI coding assistants while learning, and I reviewed and tested the code myself.
